## 导师反馈

检查日期：2026-07-27

1. `pwd` 的回答正确：它显示当前工作目录的绝对路径。
2. `git init` 创建的是 `.git` **目录**，不是普通文件。`ls -la` 中第一列以 `d` 开头也说明它是目录。
3. `main` 的回答正确：它是当前分支名。
4. `untracked files` 不是所有“暂未提交的更改”，而是“Git 从未开始跟踪的路径”。一个已经提交过的文件再次被修改时，它同样尚未提交，但状态会是 `modified`，不会回到 `untracked`。
5. `.git` 保存提交对象、分支引用、暂存区状态和仓库配置。手动删除或错误修改其中的内容，可能让提交、分支或暂存状态损坏。现阶段只通过 Git 命令操作它，不需要直接编辑内部文件。

本次验收：通过。需要在下一次任务中重点巩固 `untracked`、`staged`、`committed` 的区别。

补充反馈：

- “当前目录还不是仓库”这个判断正确。更精确地说，是需要读取仓库状态的命令找不到 `.git`；`git --version`、`git help` 等不依赖具体仓库的命令仍然可以执行。
