# ADR 0001：先学习直接模型调用，再使用 Agent 框架

- 状态：已采用
- 日期：2026-07-27

## 背景

本项目的核心目标之一是理解 AI 应用的真实执行机制。如果一开始就使用完整 Agent 框架，模型消息、工具参数校验、循环停止和错误处理容易被框架隐藏。

## 决策

前两个里程碑直接使用模型提供方的官方 SDK：

1. 先实现普通模型调用和结构化输出。
2. 再亲手实现一个规模受控的工具调用循环。
3. 能解释其机制并完成测试后，才评估是否引入 LangGraph。

## 结果

优点：

- 能看见模型与应用程序的职责边界。
- 更容易理解参数校验、超时、重试和最大步数。
- 后续可以用具体证据评价框架带来的收益。

代价：

- 早期需要自己写一些框架通常会封装的代码。
- 第一版功能不会很多。

## 重新评估条件

当工作流需要持久化状态、失败恢复、人工确认或复杂分支，并且手写实现开始明显增加维护成本时，重新评估 Agent 框架。
