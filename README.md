# Personal Research Agent

一个用于学习 AI 工程并最终可真实使用的个人研究助理项目。

这个仓库同时保存两类成果：

1. 可以运行、测试和部署的 AI 应用。
2. 从零搭建它时形成的学习记录、技术决策和复盘。

## 项目愿景

用户给出一个研究问题后，系统能够逐步完成任务拆解、资料检索、信息整理和带来源的研究笔记生成；涉及保存、修改或外部操作时，系统必须请求确认。

第一版不会直接追求“全自动 Agent”。我们会先理解普通模型调用、结构化输出和工具调用，再手写一个可控的 Agent 循环，最后才引入框架。

## 当前阶段

`M0：项目定义与工程起步`

现在只有项目与学习骨架，还没有应用代码。这是刻意的：需求、环境和版本控制基线没有弄清楚之前，不急着堆功能。

## 项目目标

- 理解大模型应用和 Agent 的实际运行机制。
- 能够独立解释、修改和调试项目中的核心代码。
- 建立测试、评测、日志、容器化、CI/CD 和部署的完整工程闭环。
- 形成可以在 GitHub / Gitee 展示的提交、文档、版本和复盘记录。

## 暂不做

- 多 Agent 协作。
- Kubernetes 和微服务拆分。
- 未经确认的写文件、发消息或其他高风险操作。
- 为了“看起来高级”而过早引入复杂框架。

## 学习方式

我们遵循以下循环：

```text
定义一个小目标
→ 学习完成它所需的最少知识
→ 你先动手实现
→ 用测试和实验验证
→ 一起复盘和重构
→ 提交并记录证据
```

协作规则见 [docs/learning/README.md](docs/learning/README.md)，完整路线见 [ROADMAP.md](ROADMAP.md)。

## 请你补全

这是你的第一个项目任务。请不要让 AI 代写，用自己的话补充下面四项：

- **目标用户：** 对研究有需求的用户
- **一个真实使用场景：** 学生上传课件进行期末复习
- **期望得到的最终产物：** 一个通用的个人研究agent助手
- **你认为“这个项目真的有用”的判断标准：** 能够做到笔记来源有出处，必要时连网搜索，能够做到客观、真实

答案不需要专业，也不要求一次正确。以后我们会用真实开发结果不断修订它。
